# Daniel Péger — portfolio

Vite + React SPA with Motion shared-layout transitions and Pixi.js.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Scripts

- `npm run dev` — Vite dev server
- `npm run build` — typecheck + production build
- `npm run preview` — preview the production build

## Deploy

Vercel detects Vite automatically. `vercel.json` rewrites deep links (`/kinja`, etc.) to `index.html` for the client router.
